<PageHeader eyebrow="Reference" title="Writing: use one spelling system">
  Both spelling systems are correct. This guide uses standard British spelling, the system most common in East Africa.
  Whichever you choose, use it the same way every time: mixing the two in one text looks like a mistake.
</PageHeader>

## Spelling

| Standard British | American |
| --- | --- |
| colour | color |
| centre | center |
| analyse | analyze |
| travelled, cancelled | traveled, canceled |
| licence (noun), license (verb) | license (both) |
| practice (noun), practise (verb) | practice (both) |
| training programme, computer program | program (both) |

Use -ise endings: organise, recognise, prioritise. (-ize is also correct in standard British spelling, but never mix the two in one document.)

## Dates

Write the month as a word: **4 May 2026**. Written as 04/05/2026, it means 4 May to you but 5 April to an American.

## False friends

These change meaning between the two styles.

| Phrase | American meaning | Meaning in Standard English |
| --- | --- | --- |
| table a proposal | postpone it | put it forward for discussion |
| quite good | very good | fairly good |
| first floor | ground floor | the floor above the ground floor |
| pants | trousers | underwear |
| momentarily | in a moment | for a moment |

## Sports idioms

Recognise them, but use the plain version: many listeners outside the US won't know them.

| American idiom | Plain English |
| --- | --- |
| ballpark figure | rough estimate |
| touch base | check in |
| step up to the plate | take responsibility |
| out of left field | unexpected |
| slam dunk | certain success |

## Grammar habits

These are not mistakes, just American.

| American | Standard English |
| --- | --- |
| I've gotten | I've got |
| Did you send it yet? | Have you sent it yet? |
| on the weekend | at the weekend |
| different than | different from |
| Monday through Friday | Monday to Friday |
